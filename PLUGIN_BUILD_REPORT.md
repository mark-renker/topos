## Design notes

* **Expansion contract honoured.** Slot engine controls are eight generic normalised
  proxies `slotN_p0..slotN_p7` (`topos::params::slotParamId`). The processor maps them to
  the current engine's `ParamSpec` with `value = min + (max-min)*pow(norm, skew)` and
  `std::round` when `stepped` (`topos::params::denormalise`). The editor re-labels,
  re-ranges the text display and hides sliders beyond `desc.numParams` at runtime from
  `EngineRegistry::descriptor()`. Adding an engine creates no parameter IDs and cannot
  break a saved session. Parameter IDs carry version hint 1.
* **Realtime safety.** All parameter pointers are cached at construction
  (`getRawParameterValue`), `RackState` is a member filled in place, and `processBlock`
  only does `rack.setState` + `rack.process` — no allocation, no locking, no
  string/parameter lookups. Blocks larger than the prepared block size are chunked with
  pointer offsets. Mono hosting uses a pre-allocated stereo scratch buffer
  (`AudioBuffer` sized in `prepareToPlay`) and folds down with `0.5*(L+R)`.
* **Oversampling.** `ToposRack::setOversampleRate()` re-prepares (allocates) every engine,
  so it must not be called from the audio thread. A 100 ms message-thread `Timer` in the
  processor watches the `oversample` choice and applies changes inside
  `suspendProcessing(true/false)`; `processBlock` only ever publishes the already-applied
  factor. The same timer caches `rack.tailSeconds()` so `getTailLengthSeconds()` is const-safe.
* Latency is reported as 0 (`setLatencySamples(0)`); the halfband oversampler's group delay
  is inside the rack and is not compensated (see below).
* State via APVTS XML (`copyXmlToBinary` / `getXmlFromBinary`, tag checked).
* Bus layouts: mono→mono and stereo→stereo only (`in == out`).

## Core observations (no core files were edited)

1. `ToposRack::prepare()` prepares all engines at `sampleRate * 4` and sets
   `preparedOsRate = 4`, while `RackState::oversample` defaults to 1. A wrapper therefore
   **must** call `setOversampleRate()` explicitly after `prepare()` or engine coefficients
   are computed for the wrong rate. The wrapper does this in `prepareToPlay`.
2. ~~Empty lanes sum to +9.5 dB~~ — **no longer true**: the core now leaves empty and
   fully bypassed lanes out of the parallel sum. Active lanes still add up (see the
   2026-11-02 Auto Gain fix below).
3. `ToposRack::process()` silently clamps `n` to `maxBlockSize`; the wrapper chunks blocks
   itself so no samples are dropped when a host sends more than the prepared block size.
4. `Halfband::push()` shifts a 31-tap state vector per sample (O(taps) per sample) and
   `RackState::useOsSafety` is accepted but not read by the rack. Both are core-side
   performance/API notes only.
5. `ToposRack::tailSeconds()` is non-const, so `getTailLengthSeconds()` (const in JUCE)
   reads a cached value refreshed on the message thread.
